# Versioning policy — BASICGOL

- Language version and library version are tracked separately (see README.md).
- Semantic versioning: MAJOR.MINOR.PATCH.
- MAJOR: breaking changes to public macros/types/API.
- MINOR: new features, backward compatible.
- PATCH: bug fixes.
- Public interface changes require a documented breaking change and a
  migration note in CHANGELOG.md.
- Examples and docs must match the implemented feature set.
