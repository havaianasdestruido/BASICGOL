# API reference — BASICGOL

Public headers live under `include/`. Include with `-I include`.

- `include/basicgol.h` — core macros, types, control flow, I/O.
- `include/basicgol/biblioteca.h` — library umbrella.
- `include/basicgol/caractere.h` — character helpers.
- `include/basicgol/consola.h` — console helpers.
- `include/basicgol/matematica.h` — math helpers.
- `include/basicgol/texto.h` — text helpers.
- `include/basicgol/utilidades.h` — utility helpers.

Link `build/libbasicgol.a` (or `.lib` on Windows) plus `-lm` where needed.
Full per-symbol reference: docs/02-referencia.md and the generated site.
